# 🏨 Sona — сайт отеля

> Учебный проект 2022 года: первый опыт серверной разработки на PHP и MySQL.

Сайт отеля с каталогом номеров, бронированием, отзывами и админкой для управления номерами.

## Возможности

- Каталог номеров и страница каждого номера с описанием, ценой и вместимостью
- Бронирование: даты заезда и выезда, количество гостей
- Отзывы к номерам
- Форма обратной связи
- Админка: добавление, редактирование и удаление номеров

## Стек

PHP (PDO), MySQL, HTML, CSS, JavaScript, Bootstrap.

## Запуск локально

1. Установите локальный сервер с PHP и MySQL, например [XAMPP](https://www.apachefriends.org/) или OpenServer.
2. Положите файлы проекта в **корень** сайта: пути в коде строятся от `DOCUMENT_ROOT`.
3. Создайте базу данных `sona` и импортируйте в неё `sona.sql`, например через phpMyAdmin.
4. Подключение к базе настраивается в `common/bd.php`. По умолчанию это `localhost`, пользователь `root`, без пароля.
5. Откройте `http://localhost/index.php`. Админка находится по адресу `/admin.php`.

## Что бы я сделала сейчас иначе
